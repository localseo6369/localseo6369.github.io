Privacy Policy

rclone Drive Access · Last updated 20 October 2026

Who uses this app

This app is a personal tool. Its only user is its owner, who uses it to reach their own Google Drive through rclone on their own computer.

What data it accesses

With the owner's permission, the app reads, uploads, moves and deletes files in the owner's Google Drive, only when the owner runs a command for it.

Where data goes

  • Files move only between Google Drive and the owner's own computer.
  • The sign-in token is stored only in a configuration file on the owner's computer.
  • No data is sent to, stored on, or shared with any server run by this app or any third party.
  • No data is sold, used for advertising, or used to train AI models.

Google API Services User Data Policy

This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
